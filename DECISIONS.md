# Решения

Журнал принятых решений. Одна строка — одно решение и причина. Читать перед тем, как предлагать смену подхода: скорее всего вариант уже рассматривали.

## Принято

- **Vanilla TS вместо React.** Три экрана и один объект состояния. Фреймворк добавляет сборку и зависимости, не решая ни одной задачи проекта.
- **Свой CSS вместо Tailwind и UI-китов.** Вся суть оформления — три несовместимые палитры и нестандартные анимации. Кит пришлось бы переопределять целиком.
- **Статика вкомпилена в Go-бинарник через `embed.FS`.** Деплой сводится к копированию одного файла. Не нужен отдельный раздатчик статики и синхронизация версий фронта и бэка.
- **Без БД, ответ пишется в JSON-файл.** Ответ ровно один. База — инфраструктура, которую придётся поднимать, бэкапить и чинить ради одной записи.
- **Telegram вместо почты для уведомления.** Приходит мгновенно на телефон, не попадает в спам, настраивается за десять минут.
- **Даты карточками, а не календарём.** Полноценный пикер — это код, локали и выбор из 365 вариантов. Три-четыре готовых варианта читаются как подготовленный сюрприз, а не как форма бронирования.
- **Один шрифт на весь сайт.** Коты различаются цветом, скоростью и формой. Три гарнитуры превратили бы сайт в ярмарку.
- **Секретный путь вместо авторизации.** Аудитория — один человек, которому ссылку отправят лично. Пароль здесь — только лишний барьер.
- **Mobile-first, десктоп не полируется.** Откроют с iPhone.

## Отвергнуто

- **Docker.** Один бинарник и systemd делают то же самое без слоя абстракции.
- **Календарь-пикер с выбором любой даты.** См. выше.
- **Разные шрифты для каждого кота.** См. выше.
- **Анимации на каждом элементе.** Движение допускается только там, где оно прописано в `CLAUDE.md`: дыхание карточек Киша, отскок карточек Ириски, оседание билета Чипса. Всё остальное — статика.

## Открыто

- Пересчитать палитры по реальным фотографиям котов, когда они появятся в `assets/img/`.
- Решить судьбу звуков: если записать кряхтение, воркование и мурчание не выйдет — убрать их из `CLAUDE.md` целиком, а не оставлять «на потом».
